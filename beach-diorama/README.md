# 迷你香港桌面擺設（Beach Diorama）

一個浮喺 Windows 桌面最上層嘅 3D low-poly 卡通迷你香港。地圖係**方形**，**陸地佔 8、維多利亞港佔 2**：右邊係一條窄身維港，有綠白色雙層**天星小輪**來回航行；其餘係海旁城市，有密集高樓天際線、後面嘅山脊、街道、霓虹招牌、海濱摩天輪，最高嗰座大廈天台有一塊**大型 LED 數字鐘**（顯示電腦本地時間），仲有**雙層電車（叮叮）同紅色的士**沿環形馬路行駛（電車同的士共用外圈路，電車有路軌）。夜晚大廈窗戶、街燈同車燈會亮，海面有燈光倒影。地圖冇牆，四邊係剖面（泥土層同水層），唔會擋住後面嘅大廈；畫面冇太陽、月亮或星星。全部用 Three.js 即時生成，冇用任何外部模型檔，冇人物，亦冇動物。用 Electron 包住，視窗約 300×300 px，背景透明，透明位置嘅點擊會穿透去底下嘅程式。

另外有**第二個地圖：九龍灣（寫實版）**，用寫實材質（窗戶玻璃、環境反光、電影式色調映射）同按真實街道佈局重現嘅街區，詳見下面「九龍灣（寫實版）」。右鍵選單可以切換三個地圖（第三個係**中環（寫實）**）。

> 迷你香港嘅海旁參考咗中環：紅褐色海濱地磚、一片草地、四條帶青綠色屋頂碼頭嘅突堤，同一幢白色圓窗大廈（以置地／怡和大廈為靈感）。呢啲係卡通化簡化，唔係按真實位置同比例。

## 需要咩

- **Node.js 22.12 或以上**（本專案用 Electron 45，佢要求 Node ≥ 22.12）。
  用 `node -v` 同 `npm -v` 檢查。未裝或者版本太舊嘅話，去 <https://nodejs.org> 下載**目前嘅 LTS 版本**安裝（LTS 係邊個大版本號會隨時間轉，請以網站顯示為準）。
- Windows 10 / 11。

## 點樣行

```
cd beach-diorama
npm install
npm start
```

- `npm install` 好快，但 Electron 45 嘅執行檔係**第一次 `npm start` 先會下載**，所以第一次會慢少少、需要上網。
- 視窗會出現喺主螢幕工作區嘅**右下角**（喺工作列上面，留 20 px 邊距）。
- 想閂：右鍵撳小島 →「結束 (Quit)」。

## Windows 免安裝版（單一 .exe）

只得**一個檔案** `HongKongDiorama-<版本>-portable.exe`：唔使安裝、唔使裝 Node.js，雙擊就開；想閂就右鍵選單「結束」，想刪就直接刪檔案。app **冇**開機自動啟動功能（程式碼冇用 `setLoginItemSettings`），所以唔會喺開機時自己開，要用先自己開。設定（光線、地圖、位置）會存喺 `%APPDATA%`。

- **自動**：喺 repo 推一個 `v` 開頭嘅 tag（例如 `v1.1.0`），GitHub Actions 喺 Windows 機器上建好呢個 exe，貼去該 tag 嘅 Release，亦會放入 workflow 嘅 Artifacts。
- **手動**：GitHub → Actions →「Build Windows portable exe」→ Run workflow（要 workflow 檔已喺預設分支先見到按鈕），完成後喺該次執行頁面底部下載 Artifacts。
- **自己喺 Windows 建**：`cd beach-diorama && npm install && npm run dist`，成品喺 `dist/`。

**如果開唔到／畫面冇出**：app 起唔到 3D 場景（或渲染程序當機）時，會自動降級重開——先用軟件渲染（`--software`），再用精簡模式（`--lite`：冇陰影、冇抗鋸齒、冇中文招牌字）。全部都失敗先彈錯誤框。啟動過程每一步都寫入 `%APPDATA%\beach-diorama\diorama.log`（亦記錄顯示卡資料），回報問題時請貼呢個檔案。

注意：exe **冇數碼簽署**，Windows SmartScreen 可能警告「無法辨識嘅 app」，要撳「更多資訊 → 仍要執行」。免安裝版每次啟動要先自行解壓，開得會慢幾秒。圖示係我生成嘅簡單示意圖（`build/icon.png`）。我喺 Linux 驗證過打包設定同 asar 內容，但**冇喺真 Windows 上行過 CI 或呢個 exe**，請你試完回報。

## 操作

| 動作 | 效果 |
|---|---|
| 左鍵拖曳 | 旋轉鏡頭（有慣性；唔會去到島底下） |
| 滑鼠滾輪 | 縮放，**朝住游標位置放大**（地圖式）：可以一路 zoom 入去街道，見到舖面、冷氣機、街燈等細節；縮返出嚟會自動置中，最遠大約縮到 60% |
| 右鍵撳小島 | 開選單 |
| 撳透明位置 | 穿透去底下嘅視窗，唔會擋住你 |

唔可以平移（pan），但 zoom 入去時鏡頭會跟住游標移動（有範圍限制）；亦唔可以將鏡頭轉去島底下。想睇街道高度，可以先 zoom 入再將鏡頭壓低（向下拖曳）。

**Zoom 入去嘅細節**（兩個地圖都有，縮遠就自動隱藏，慳效能）：每幢樓底層嘅舖面同雨篷、冷氣機、露台、天台水箱同天線；街燈、斑馬線、交通燈、巴士站、長凳、行人路旁邊嘅細樹；馬路加咗行人路同中線，另外有雙層巴士行走。九龍灣嘅窗戶貼圖亦提升到 256 px（有窗框同窗台）。呢啲細節係程式按樓宇位置自動生成，**唔係真實店舖或街道設施**。

## 時間顯示

最高嗰座大廈天台有塊大 LED 數字牌，顯示你部電腦嘅**本地時間**（24 小時制 `HH:MM`，冒號每秒閃一下）。牌面會自動轉向鏡頭，點樣旋轉都睇得到；夜晚會亮啲。

## 右鍵選單

| 項目 | 做咩 |
|---|---|
| 日間 (Day) | 預設。藍天色調、暖色陽光 |
| 日落 (Sunset) | 橙粉紅光線、低角度長影、玻璃反映粉橙天空、金黃至粉紫嘅海水 |
| 夜晚 (Night) | 深藍光線，大廈窗戶同招牌亮燈 |
| 地圖：迷你香港 (卡通) / 地圖：九龍灣 (寫實) | 切換地圖（會重新載入畫面，約幾秒）。**會記住** |
| 移動位置 (Move position) | 視窗頂部出現一個**拖曳控點**（同埋白色外框），按住控點就可以搬視窗。移動期間成個視窗會接收滑鼠（唔穿透），搬好再揀「鎖定位置」 |
| 鎖定位置 (Lock position) | 移動模式中先出現（取代「移動位置」）。收起控點、恢復穿透，並**記住位置** |
| 重設視角 (Reset view) | 鏡頭角度同縮放回到預設（有短短動畫） |
| 結束 (Quit) | 閂 app |

- 三個光線模式之間會用約 **2 秒**平滑過渡。
- **上次揀嘅光線模式**、**地圖**同**視窗位置**會記住，下次開機自動還原。
- 如果記住嘅位置喺已拔走嘅螢幕外面，會自動跳返去右下角預設位置。

設定檔喺 Electron 嘅 userData 資料夾，Windows 通常係 `%APPDATA%\beach-diorama\settings.json`（內容好簡單：`{ "mode": "day", "map": "hk-mini", "position": { "x": …, "y": … } }`）。刪咗佢就會還原預設。

## 效能

- 渲染上限約 **30 fps**，像素比最多 2（`Math.min(devicePixelRatio, 2)`）。
- 迷你香港：約 77 個 mesh、約 18,000 個三角形（每幀約 94 次 draw call）。九龍灣：約 240 幢樓合併成一個 mesh，約 9 萬個三角形，只有約 50 次 draw call，但三角形多同材質重，**對 GPU 要求高啲**（陰影貼圖已降到 1024）。頁面被判定為隱藏（`document.hidden`）時會暫停渲染。
- 我喺冇真 GPU 嘅 Linux container 量過：迷你香港每幀 JS 約 0.6 ms；九龍灣約 2.2 ms。**Windows 上嘅實際 CPU／GPU 用量我冇量過**，請自己量。如果九龍灣版嘅 GPU 偏高，可以將 `renderer.js` 嘅 `FPS` 降低。
- 想睇 CPU：開工作管理員 →「詳細資料」→ 搵 `electron.exe`（會有幾個程序：主程序、renderer、GPU），加返「GPU」欄一齊睇。主要成本喺 GPU 程序，真 GPU 上應該好輕；如果見到 GPU 程序 CPU 好高，多數係 Chromium 退回咗軟件渲染（例如 GPU 驅動黑名單）。

- Zoom 入去之後，近景細節先會顯示（我量到：迷你香港約 1.7 萬個三角形、九龍灣約 14.7 萬個，已按區域分成幾十塊，視野外嘅會被略過），所以三角形數量會明顯增加；而且 zoom 入去時陰影範圍會收窄、較清晰。我只喺 Linux 軟件渲染環境睇過畫面同量過 JS 時間，**Windows 真 GPU 上 zoom 入去嘅幀率我冇量過**。細節層用距離開關，所以開關瞬間會「彈出」，冇淡入淡出。

## 疑難排解

**透明位置撳唔穿／島上面撳唔到**

預設用 `setIgnoreMouseEvents(true, { forward: true })`，由頁面用射線偵測（raycast）判斷游標係咪喺小島上面。如果喺你部機唔可靠，可以轉用備用方案「輪詢（poll）」：主程序每 40 ms 讀取游標位置，再叫頁面判斷。

```
npm start -- --click-through=poll
```

或者（PowerShell）：

```
$env:DIORAMA_CLICK_THROUGH = 'poll'; npm start
```

仲有 `off`：成個 300×300 視窗永遠接收滑鼠，唔穿透（最穩陣，但會擋住底下少少地方）。

**其他**

- `DIORAMA_DEBUG=1` 係開發／測試用嘅除錯模式（會開放測試用 hook 同 DevTools 權限），平時唔需要。
- 視窗被其他「最上層」程式蓋住：Windows 嘅「螢幕保護程式」層級已經係 Electron 提供最高嘅一級，但全螢幕獨佔遊戲仍然可能蓋過佢。

## 檔案結構

```
package.json      npm start
main.js           視窗、穿透、右鍵選單、設定儲存（Electron 主程序）
preload.js        contextBridge，只開放最少嘅 IPC
index.html        載入 Three.js（import map 指去 node_modules）、CSP
styles.css        透明背景、拖曳控點
renderer.js       場景組裝、相機、30 fps 迴圈、穿透用嘅 raycast
scene/
  util.js         共用物料、合併幾何、極座標網格
  island.js       方形地圖：城市地面、山、海岸線、剖面側邊同底座
  sea.js          海面（逐頂點波浪）+ 沿海岸線嘅泡沫
  layout.js       街道規劃：兩條環形路、橫街、樓宇分區、地標
  city.js         大樓、窗戶、山脊樹林、招牌、摩天輪、天台大鐘
  traffic.js      道路、電車路軌、雙層電車、紅的士
  ferry.js        天星小輪
  lighting.js     日間／日落／夜晚光線 + 2 秒過渡 + 距離霧氣
  harbourlights.js 夜晚海面燈光倒影
  textures.js     光暈、燈光條紋嘅小貼圖
  details.js      近景細節（舖面、冷氣機、街燈…）嘅共用生成器同分區合併
  streetscape.js  迷你香港嘅街道細節佈置
  clockboard.js   天台大型 LED 數字鐘（兩個地圖共用）
  worlds/minihk.js    迷你香港（卡通）
  worlds/realmap.js   寫實地圖（九龍灣、中環共用，按資料檔生成）
  real/           九龍灣同中環嘅資料檔、立面貼圖、水面、幾何工具
tools/
  csp-hash.js     改咗 import map 之後用嚟重新計 CSP hash
  osm-to-map.mjs  將 OpenStreetMap 匯出檔轉成九龍灣版嘅地圖資料（見下面）
  sync-web.mjs    砌出獨立嘅網頁預覽資料夾（含 Three.js，唔靠 CDN）
web/              網頁預覽用嘅頁面、shim 同按鈕（同桌面版共用 renderer.js）
```

安全設定：`contextIsolation: true`、`nodeIntegration: false`、`sandbox: true`，頁面有 Content-Security-Policy，唔准導航同開新視窗。

**改 `index.html` 入面嘅 import map 之後**，要行 `node tools/csp-hash.js`，將輸出嘅 hash 貼返入 `<meta http-equiv="Content-Security-Policy">` 嘅 `script-src`，否則頁面會被 CSP 擋住而成片空白。

## 九龍灣（寫實版）

右鍵 →「地圖：九龍灣 (寫實)」。視窗範圍大約 1.4 公里見方：左下角係九龍灣海面同填海地，啟祥道、承啟道、偉業街、宏照道、常悅道、常怡道等主要道路，右邊係 MTR 路軌走廊同車廠，有公園、MegaBox（天台有大型數字鐘）、君立酒店、歷山文儀中心、香港兒童醫院、九龍灣站等地標。街上有紅的士、私家車、貨車、雙層巴士同小巴，全部跟住馬路行（每條路分兩條線，靠左行車，去到路尾掉頭返嚟；唔同道路相交嘅地方車輛會互相穿過，冇做紅綠燈同避讓），路軌上有 MTR 列車（行到地圖邊界會被切走）。

**資料準確度（重要）**

- 呢個版本係我**照一張 Google Maps 截圖用手描出嚟**嘅：道路、公園、海岸同地標位置係我**用眼睇住截圖描出嚟**，**冇量度過誤差**；視窗大約 1.4 公里見方呢個比例亦係**估計**（約 1.5 米／像素）。**樓宇高度係估計**；一般樓宇嘅位置同大小係程式按街區自動填充，**唔係每幢真實樓宇**。截圖本身冇放入 repo。
- **授權提醒（唔係法律意見）**：呢份座標係參考 Google Maps 截圖描出嚟，Google 嘅條款一般限制由其地圖衍生資料。自己用冇問題；如果要公開分享 repo 或網頁，建議先用下面嘅 OpenStreetMap 方法換成開放資料。
- 想用真實資料：喺有網絡嘅機器匯出 OpenStreetMap，再轉換：

```
node tools/osm-to-map.mjs --query 22.3215 114.2100 1400    # 印出 Overpass 查詢，貼去 https://overpass-turbo.eu 匯出 JSON
node tools/osm-to-map.mjs overpass.json scene/real/kowloonbay.data.js 22.3215 114.2100 1400
```

  轉換後每幢樓用真實樓宇輪廓嘅方形外框（唔係完全貼合多邊形），層數取自 `building:levels`（冇就預設 8 層）。資料來源 © OpenStreetMap contributors（ODbL），公開發佈請保留署名。

  **已知限制**：OSM 通常用「未封閉」嘅海岸線畫海，而呢個工具只識封閉嘅水域多邊形，所以真實匯出檔大概率**搵唔到海灣**（九龍灣會變成全陸地）。可以加 `--keep-water=scene/real/kowloonbay.data.js` 沿用我描嘅海同填海地多邊形（但你揀嘅中心同範圍要同我描嘅一樣先對得上，我冇驗證過）。我嘅環境連唔到 OpenStreetMap，所以呢個工具只用小型模擬資料測試過，**未用真實匯出檔試過**。
- **樓宇外觀**（參考實景相片）：高樓用鏡面玻璃幕牆（深藍、青綠、藍色，反光較強），辦公樓用米色／啡色橫帶窗，住宅用奶油色／粉紅色窗格，部份矮樓有弧形轉角；MegaBox 係紅橙色八角形平台（有拱形玻璃窗同「megaBOX」字樣），後面升起玻璃塔樓；另外有八角形棕色企業廣場、弧形玻璃高樓、車廠藍色屋頂，以及常悅道旁邊有太陽能板嘅圓形零碳天地公園。矮樓有平台式混凝土屋頂。呢啲係按相片感覺用程式按區域同層數自動分配，**唔係逐幢真實外觀**。
- 九龍灣版用 `renderer.toneMapping`、環境反光同 PBR 材質，同卡通版風格唔同，亦較食 GPU。

## 中環（寫實版）

右鍵 →「地圖：中環 (寫實)」。畫面北面係樹木茂密嘅山坡，南面係維港：海濱有紅褐色行人路、一片草地、四條帶青綠色屋頂碼頭嘅突堤同一個摩天輪；街道有干諾道中、德輔道中、皇后大道中、威靈頓街、夏慤道同幾條直街，車輛沿住道路行。地標包括國際金融中心二期（分級收窄加塔尖）、國際金融中心一期、中銀大廈（四柱不同高度）、怡和大廈（圓窗）、長江集團中心（天台數字鐘）、匯豐、大會堂、力寶中心同太古廣場。

**準確度（重要）**：呢個版本係我**參考兩張中環鳥瞰截圖，憑眼睇自己畫出嚟嘅簡化佈局**（資料喺 `scene/real/central.data.js`），街道位置、地標位置、大小同層數都係**估計**，唔係量度或描圖，亦冇用 OpenStreetMap；一般樓宇由程式按街區自動填充。山坡冇起樓，亦冇高架路同半山樓宇。

## 網頁預覽

```
node tools/sync-web.mjs ./web-preview
```

會砌出一個獨立資料夾（頁面、共用嘅 `renderer.js` 同 `scene/`、內置嘅 Three.js），用任何靜態伺服器打開 `index.html` 就得，網址加 `#kowloon-bay`、`#central` 或 `#hk-mini` 揀地圖。網頁版冇透明穿透、置頂同記住位置。
