# Yo Jie 桌面寵物（Windows）

透明、冇邊框、永遠喺最頂嘅細視窗，桌面上淨係見到 Yo Jie 坐喺佢張書枱度做嘢，冇背景。

## 佢會做乜

- **打字**（平時）：手喺電腦後面一下一下咁打，膊頭跟住郁，間中停一停
- **望吓你**：抬頭笑住望你（用你第二張圖嘅樣）
- **諗嘢**：側頭、眼望上面
- **伸懶腰**：成個人伸高少少、合埋眼
- **瞇一陣**：合埋眼、個頭慢慢垂低再撐返起身，頭頂飄「z」
- 會自己眨眼；眼睛跟住滑鼠望（成個螢幕都得）
- 枱面嗰個透明牌仔會顯示而家幾點同日期（右鍵可以熄）

## 用法

- **撳佢**：開心笑一笑、出心心；瞇緊眼就會醒返望你
- **拖佢**：搬去桌面其他位置
- **右鍵**：自動開關、揀動作、牌仔顯示時間、大細（細／中／大）、永遠置頂、離開
- 佢同張枱以外嘅透明位置撳落去會穿過去下面嘅視窗

## 安裝

GitHub repo → **Actions → Yo Jie desk pet (Windows)** → 最新成功嗰次 → 底部 **Artifacts** 下載 `YoJie-windows`：

- `YoJie-1.0.0-portable.exe`：撳兩下就開
- `YoJie-1.0.0-setup.exe`：安裝版（想開機自動開就揀呢個，再將捷徑放入 `shell:startup`）

冇數碼簽署，第一次開 Windows 會話「不明發行者」：撳「其他資訊」→「仍要執行」。

## 安全設定

同熊仔一樣：唔上網、唔讀你嘅檔案、唔改 registry；畫面喺 sandbox 入面行；用有安全更新嘅 Electron 同鎖死版本嘅套件，GitHub 整嘅時候會跑 `npm audit`。

## 原始碼

- `pet.src.html`：動畫（WebGL 網格令頭、膊頭、手、眼郁）
- `art/`：去咗背景嘅兩張圖（`yojie_base` 係主圖，`yojie_glance` 係望你嗰個樣）
- `python3 build.py`：將兩張圖嵌入，整出 `pet.html`
- `npm start`／`npm run dist`：試／整 exe
