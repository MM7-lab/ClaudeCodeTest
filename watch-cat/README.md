# 手錶貓貓（Wear OS 版）

電腦版「桌面貓貓」嘅手錶版本，適用於 Samsung Galaxy Watch（Wear OS 4 或以上，例如 Galaxy Watch Ultra）。
獨立運作，唔使手機 app，亦唔會同電腦版同步。

## 有咩功能

- **寵物主畫面**：11 種貓、7 種狗（同電腦版一樣），會呼吸、眨眼、搖尾。輕按會出心心。
  外圈係倒數圈，顯示距離下次提醒仲有幾耐。向上掃就會見到「今日」頁。
- **提醒**：飲水 → 休息 → 飲水 → 去廁所，輪流提。可以揀每 15–90 分鐘提一次。
  - 每種提醒震法唔同，唔使望都知係咩：
    - 💧 飲水：兩下短震
    - 🙆 休息：一下長震
    - 🚽 去廁所：三下快震
  - 撳「搞掂 ✓」就記錄落今日統計；撳「遲啲先 ⏰」5 分鐘後再提。
  - 唔理佢嘅話，每 5 分鐘再震一次，最多 3 次。
  - 可以揀「強力震動」。
- **夜間靜音**：預設 23:00 至 08:00 唔會提醒，寵物會瞓覺。
- **行路當休息**：到休息時間，如果你已經行咗 200 步（可以改），就當你休息咗，唔使再提。
- **今日統計**：飲水、休息、去廁所、摸咗寵物幾多次，連過去 7 日飲水棒形圖。
- **開心指數**：只會升唔會跌，每朝重新開始。
  - 開心：會搖尾、出心心
  - 好開心：頭上有花 🌸
  - 超開心：戴皇冠 👑，仲會跳舞
- **資訊卡（Tile）**：寵物、倒數圈、今日飲咗幾杯，撳「+1 杯水」就記一杯。
  如果有提醒等緊你，個掣會變成「搞掂 ✓」。
- **小部件（Complication）**：放喺錶面上，顯示「今日飲水 3/8」。
- 如果開咗「請勿打擾」或睡眠模式，就唔會震。

## 安裝（用 Windows 電腦，經 Wi-Fi）

呢個 app 冇上架 Google Play，要自己裝（sideload）。只需要做一次設定，之後更新都係咁裝。

### 1. 喺手錶開啟開發者選項

1. 手錶：**設定 → 關於手錶 → 軟件資訊**（名稱或會略有不同）。
2. 連續輕按 **「軟件版本」** 7 次，直至見到「已開啟開發者模式」。
3. 返去 **設定**，最底會多咗 **「開發者選項」**。
4. 入去開啟 **「ADB 偵錯」** 同 **「無線偵錯」**（透過 Wi-Fi 偵錯）。

> 手錶同電腦要連住**同一個 Wi-Fi**。

### 2. 喺電腦準備 adb

1. 喺 Google 官方網頁下載 **Android SDK Platform-Tools（Windows）**：
   <https://developer.android.com/tools/releases/platform-tools>
2. 解壓縮，例如放喺 `C:\platform-tools`。
3. 喺嗰個資料夾，按住 Shift 再撳滑鼠右鍵，揀「在終端機中開啟」（或者開「命令提示字元」再 `cd C:\platform-tools`）。

### 3. 配對同安裝

1. 手錶：**開發者選項 → 無線偵錯 → 配對新裝置**，會見到 IP 位址、連接埠同配對碼。
2. 電腦打（換成手錶顯示嘅數字）：
   ```
   adb pair 192.168.1.23:41234
   ```
   然後輸入手錶上嘅 6 位配對碼。
3. 返去「無線偵錯」主畫面，睇 **IP 位址同連接埠**（同配對嗰個唔同），電腦打：
   ```
   adb connect 192.168.1.23:39876
   ```
4. 將下載咗嘅 `WatchCat-1.0.0.apk` 放入同一個資料夾，然後：
   ```
   adb install -r WatchCat-1.0.0.apk
   ```
   見到 `Success` 就裝好喇。

> 之後出新版本，用同一句 `adb install -r ...` 就可以直接覆蓋，設定同紀錄都會保留。
> 裝好之後可以返去開發者選項熄咗「無線偵錯」，慳電。

### 4. 第一次打開

1. 喺手錶 app 列表搵 **「手錶貓貓」**。
2. 佢會問兩個權限，請撳「允許」：
   - **通知**：用嚟提醒你。
   - **體能活動**：用嚟數步數（「行路當休息」要用）。唔俾都得，只係呢個功能唔會用到。
3. 向上掃去「今日」頁，撳 **⚙️ 設定** 揀寵物、改名、改提醒時間。
4. 喺設定撳 **🔔 試吓提醒**，可以試吓震法同提醒畫面。

### 5. 加資訊卡同小部件

- **資訊卡**：喺錶面向左掃，掃到最尾撳「＋」，揀 **「貓貓提醒」**。
- **小部件**：長按錶面 → **自訂** → 揀一個小部件位置 → 揀 **手錶貓貓 / 今日飲水**。
  （唔係每個錶面都有小部件位置；Samsung 嘅數字錶面一般都有。）

## 開發

- `core/`：純 Kotlin，冇 Android。包括寵物畫法（`PetArt`）、提醒規則（`Reminders`）、統計同開心指數（`Stats`）。
  可以單獨喺電腦測試：`cd core && gradle test`，會喺 `core/build/previews/` 畫出全部寵物嘅 PNG。
- `app/`：Wear OS app（Compose for Wear OS、Tiles、Complications）。
- GitHub Actions（`.github/workflows/watch-cat.yml`）會自動編譯，並上載 `WatchCat-x.y.z.apk`。
- `keystore/sideload.jks` 係一條固定嘅簽名鎖匙（密碼 `watchcat`），只係用嚟令新版本可以直接覆蓋舊版本，**唔好用嚟簽其他嘢**。
