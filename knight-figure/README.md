# 小貓騎士收藏公仔（WebGPU）

一個獨立 HTML 檔（`index.html`），用原生 WebGPU + WGSL 即時渲染一隻 PVC／搪膠質感嘅小貓騎士公仔。冇用任何外部函式庫、圖片、字型或模型檔：形狀、物料同燈光全部喺程式入面生成。

要用支援 WebGPU 嘅瀏覽器，例如新版 Chrome、Edge 或 Safari。唔支援嘅話，頁面會顯示說明。

## 兩個版本

| 版本 | 配件 | 動作 |
|---|---|---|
| Knight（騎士） | 長劍 | Salute：舉劍敬禮、點頭 |
| Tea Break（茶歇） | 港式奶茶杯，加一件透明 PVC 蒸氣件 | Sip：飲一啖、抬頭、放低杯，再呼出一口慢慢散開嘅白氣 |

## 操作

- **拖曳**：轉鏡頭；滾輪或兩指捏：縮放。
- **Fixed**（預設開）：公仔企定喺度，拖曳只會轉鏡頭，Drop 會停用。
- 熄咗 Fixed：可以捉起公仔、拋出去，佢會彈、會跌、會滾，最後停定（公仔本身唔會變形）；**Drop** 會由高處跌落嚟。
- **Reset**：返回原位。**Spin**：轉盤慢慢轉。
- **Pose**：拖個頭或者隻手擺姿勢。關節有角度限制；手、劍同杯撞到身體或者個頭就會停，唔會穿模。擺手時劍會保持大致垂直，茶杯會保持水平。
- **Load model**：載入自己嘅模型（下面有詳情）。

## 載入自己嘅模型

- 支援 `.glb`、`.gltf`（連 `.bin` 同貼圖一齊揀）、`.obj`（可連 `.mtl` 同貼圖）、`.stl`。
- 支援基本顏色、貼圖、頂點顏色、多種物料同節點變換。
- 冇法線嘅模型會自動計：30° 以上嘅摺角保留硬邊。
- Z 軸向上嘅 STL 會自動企返直。
- 模型會自動縮放到公仔大細、置中，透明底座按模型腳底大細調整，鏡頭自動對準，再用 GPU 烘焙陰影（AO）。
- 可以揀 Gloss／Satin／Matte 三種表面；冇貼圖嘅模型可以揀油色。
- 方向唔啱可以撳「Stand up ↻」或「Turn ↻」。物理、Fixed 同 Spin 照樣用得。
- 「Back to Knight Kitten」返回小貓騎士。
- Draco／meshopt 壓縮、`.gltf` 漏咗 `.bin`、有骨架嘅模型（會以靜止姿勢顯示），都會出提示話你知點處理。

## 檔案

| 路徑 | 用途 |
|---|---|
| `index.html` | 成品（由 `build.sh` 產生，唔好直接改） |
| `src/` | 原始碼：數學、SDF 雕塑、網格生成、著色器、渲染、物理、模型載入、介面 |
| `build.sh` | 將 `src/` 砌成 `index.html` |
| `test/` | 無頭 Chromium（SwiftShader WebGPU）自動測試同截圖；`gen_models.py` 產生測試用模型 |

## 改完之後

```
./build.sh                         # 重新產生 index.html
python3 test/gen_models.py         # 第一次跑測試前產生測試模型
node test/t1.cjs                   # 例如：開機時間、錯誤檢查同主截圖
```

測試要先裝好 Playwright。無頭模式下，WebGPU 畫布喺測試環境會令裝置斷線，所以測試會用離屏材質渲染再讀返像素截圖；真正瀏覽器就照常直接畫落畫布。
