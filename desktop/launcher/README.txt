Plush Toy Box / 毛公仔玩具箱

How to open
  Double-click "Plush Toy Box.cmd". It opens in its own Microsoft Edge window.
  Keep the "app" folder next to it.

開法
  雙擊「Plush Toy Box.cmd」，會用 Microsoft Edge 開一個獨立視窗。
  「app」資料夾要同佢放喺同一個位置。

Tips
  - Pin it: right-click the window's taskbar icon > Pin to taskbar.
  - F11 toggles full screen.
  - If you see "needs WebGPU", update Edge (Settings > About Microsoft Edge)
    and make sure "Use graphics acceleration when available" is on (Settings > System and performance).
