# 角色生圖 prompt（方法三：插畫乘客）

每張圖都係「共用風格」＋「角色描述」＋「姿勢」三段一齊貼。生好之後用表入面嘅檔名上載。

## 共用風格（每張都要貼喺最前面）

```
Clean cartoon character illustration, same style as a webtoon character design sheet: bold dark outlines, flat cel colours with soft shading, natural adult proportions, warm and dignified (not caricatured), Hong Kong everyday clothing. ONE full-body figure only, centred, feet fully visible, plain flat light grey background (#E3E3E3), no grid, no text, no labels, no colour swatches, no extra sketches, nothing touching the figure, no logos.
```

## 生圖規矩

- 一張圖一個人、一個姿勢，全身，見到對腳。
- 坐嘅姿勢一律寫 `sitting on an invisible seat (no chair drawn), facing the viewer`，唔好畫凳。
- 拎電話只用一隻手。
- 如果工具可以上載參考圖，上載婆婆或者 A–F 設定圖，畫風會比較一致。
