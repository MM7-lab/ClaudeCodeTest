# 桌面貓貓 🐾

一隻 3D 貓貓喺你個桌面底部行嚟行去，自己玩自己嘅：散步、跑圈、坐低、舔毛、伸懶腰、打喊路、瞓覺，間中仲會追你個滑鼠。佢每 30 分鐘會輪流提你飲水、休息、去廁所。

成個介面都係香港繁體中文。

## 下載同安裝

1. 去呢個 repo 嘅 **Actions** → **Build Desktop Cat** → 揀最新一次（有綠色剔嗰次）。
2. 喺頁面底部 **Artifacts** 下載，解壓：
   - **Windows**：`DesktopCat-Windows`，入面有安裝檔 `DesktopCat-1.0.0-win-x64.exe`，同免安裝版 `DesktopCat-1.0.0-portable.exe`。
   - **Mac**：`DesktopCat-macOS`，入面有 `DesktopCat-1.0.0-mac-universal.dmg`（Intel 同 Apple 晶片都用得）。
3. 第一次開：
   - **Windows**：因為冇數碼簽署，可能會彈「Windows 已保護您的電腦」。撳「其他資訊」→「仍要執行」。
   - **Mac**：打開 dmg，將 DesktopCat 拖入「應用程式」。開嘅時候如果話「無法打開」，去「系統設定」→「私隱與安全性」，喺下面撳「仍要打開」。如果話個 app「已損毀」，開「終端機」打：`xattr -cr /Applications/DesktopCat.app`，再開過。

## 點用

- 貓貓會喺螢幕底部（工作列上面）出現。除咗貓貓本身，其他地方照常撳到你啲程式。
- **撳一下貓貓**：摸摸佢 💗
- **滑鼠喺佢身上掃嚟掃去**：掃毛，佢會呼嚕呼嚕
- **撳住拖走**：揸起佢；放手佢會跌返落地（掟得大力佢會嬲 😾）
- **滑鼠喺螢幕底部快快郁**：佢可能會撲過嚟玩
- **右撳貓貓**，或者撳工作列右下角（Mac：螢幕頂嘅選單列）嘅貓貓圖示，就會開選單：暫停／繼續提醒、即刻提醒一次、叫貓貓過嚟、收埋貓貓、設定、離開。

## 提醒

- 每隔 30 分鐘（設定入面可以改 15–90 分鐘），輪住提：💧 飲水 → 🙆 休息伸展 → 💧 飲水 → 🚽 去廁所。
- 夠鐘嘅時候，貓貓會行埋嚟坐低望住你、跳兩下、喵兩聲，再出對話框，同埋彈系統通知。
- 撳「**搞掂 ✓**」會記低一次；撳「**遲啲先（5 分鐘）**」就 5 分鐘之後再提。唔理佢嘅話，每 5 分鐘再喵一次，最多 3 次。
- 如果你離開電腦（冇郁滑鼠同鍵盤）超過 5 分鐘，貓貓會當你休息咗，返嚟之後重新計時。

## 設定

右撳貓貓 →「設定…」：

- 貓貓個名、毛色（橙色虎斑、灰色虎斑、黑貓、白貓、黑白貓）、大細
- 提醒間隔、提醒邊幾樣、要唔要佢間中講鼓勵說話
- 喵喵聲、音量、開機自動啟動
- 今日紀錄：飲咗幾多杯水、休息咗幾多次、去咗幾多次廁所、摸咗貓貓幾多次

設定同紀錄只會儲喺你自己部電腦。

## 自己改同試

要先裝 [Node.js](https://nodejs.org/)（22 或以上）。

```
cd desktop-cat
npm install
npm start        # 直接開嚟試
npm run dist     # 整安裝檔，放喺 dist/
```

每次 push 改動 `desktop-cat/` 入面嘅檔案，GitHub Actions 都會自動重新整 Windows 同 Mac 版本。

## 檔案

| 路徑 | 用途 |
|---|---|
| `main.js` | 主程式：透明全螢幕視窗、工作列圖示、提醒計時、通知、設定儲存 |
| `preload.js` | 主程式同畫面之間嘅橋 |
| `pet/cat.js` | 3D 貓貓模型同姿勢（用 three.js 砌出嚟） |
| `pet/pet.js` | 貓貓嘅行為：行、坐、瞓、追滑鼠、拖放、提醒對話框 |
| `pet/sound.js` | 喵喵聲同呼嚕聲（即場合成，唔使聲音檔） |
| `settings/` | 設定視窗 |
| `assets/` | 圖示 |
